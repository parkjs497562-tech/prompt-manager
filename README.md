# 나만의 프롬프트 관리 프로그램

Python으로 제작한 콘솔 기반 프롬프트 관리 프로그램입니다.

자주 사용하는 생성형 AI 프롬프트를 카테고리별로 관리하고, 검색, 즐겨찾기, 수정, 삭제, 조회수 및 카테고리별 통계 기능을 통해 프롬프트를 편리하게 관리할 수 있도록 만들었습니다.

## 프로젝트 소개

이 프로그램은 생성형 AI를 활용하면서 자주 사용하는 프롬프트를 하나의 프로그램에서 관리할 수 있도록 제작했습니다.

Python의 리스트와 딕셔너리를 활용하여 프롬프트 데이터를 저장하고, 콘솔 메뉴를 통해 프롬프트 추가, 조회, 검색, 상세 보기, 즐겨찾기, 수정, 삭제 등의 기능을 제공합니다.

## 개발 환경

* Python 3.12
* Visual Studio Code
* Git
* GitHub

## 실행 방법

터미널에서 프로젝트 폴더로 이동한 후 다음 명령어를 실행합니다.

```bash
python3 main.py
```

## 주요 기능

### 1. 프롬프트 추가

새로운 프롬프트의 제목, 내용, 카테고리를 입력하여 추가할 수 있습니다.

* 제목과 내용이 비어 있는 경우 입력 거부
* 기본 카테고리 선택 가능
* 새로운 카테고리 직접 입력 가능
* 새로운 프롬프트의 즐겨찾기 상태는 기본적으로 해제

### 2. 프롬프트 목록

등록된 모든 프롬프트를 번호, 카테고리, 제목과 함께 확인할 수 있습니다.

* 즐겨찾기 프롬프트는 ⭐ 표시
* 등록된 프롬프트 개수 표시

### 3. 카테고리별 조회

원하는 카테고리를 선택하여 해당 카테고리에 등록된 프롬프트만 조회할 수 있습니다.

### 4. 프롬프트 검색

검색어를 입력하여 프롬프트의 제목 또는 내용에 해당 검색어가 포함되어 있는지 확인합니다.

### 5. 프롬프트 상세 보기

프롬프트 번호를 선택하여 다음 정보를 확인할 수 있습니다.

* 제목
* 카테고리
* 즐겨찾기 상태
* 조회수
* 전체 프롬프트 내용

상세 보기를 실행할 때마다 해당 프롬프트의 조회수가 1씩 증가합니다.

### 6. 즐겨찾기 관리

프롬프트를 선택하여 즐겨찾기를 추가하거나 해제할 수 있습니다.

### 7. 즐겨찾기 목록

현재 즐겨찾기로 설정된 프롬프트만 따로 확인할 수 있습니다.

### 8. 프롬프트 삭제

프롬프트 번호를 선택하여 원하는 프롬프트를 삭제할 수 있습니다.

삭제 전에 확인 과정을 거쳐 실수로 삭제하는 것을 방지합니다.

### 9. 프롬프트 수정

기존 프롬프트의 제목, 내용, 카테고리를 수정할 수 있습니다.

### 10. 카테고리별 통계

현재 등록된 프롬프트를 카테고리별로 집계하여 확인할 수 있습니다.

* 카테고리별 프롬프트 개수 표시
* 전체 프롬프트 개수 표시

## 기본 카테고리

* 텍스트 생성
* 이미지 생성
* 영상 생성
* 페르소나
* 자동화
* 기타

사용자가 새로운 카테고리를 직접 입력할 수도 있습니다.

1. AI 게임 산업 영향 분석
2. Home Barista 커피 제품 이미지
3. 베이스온 야구 광고 영상

## 데이터 구조

프롬프트 데이터는 Python의 리스트와 딕셔너리를 사용하여 관리합니다.

각 프롬프트는 다음과 같은 정보를 가지고 있습니다.

* `title` : 프롬프트 제목
* `content` : 프롬프트 내용
* `category` : 프롬프트 카테고리
* `favorite` : 즐겨찾기 여부
* `views` : 프롬프트 조회수

```text
5. 프롬프트 상세 보기
6. 즐겨찾기 관리

9. 프롬프트 수정
10. 카테고리별 통계

================================
```

## Git 관리

Git을 사용하여 프로젝트의 변경 사항을 관리했습니다.

주요 Git 작업:

* `init`
* `add`
* `commit`
* `push`
* `pull`
* `checkout`
* `merge`
* `clone`

또한 `feature-improve` 브랜치를 생성하여 기능을 수정한 후 `main` 브랜치에 merge하는 작업을 진행했습니다.

## 프로젝트 실행 화면

프로그램을 실행하면 터미널에서 메뉴를 선택하여 프롬프트를 관리할 수 있습니다.

주요 기능으로 프롬프트 추가, 목록 조회, 검색, 상세 보기, 즐겨찾기, 삭제, 수정, 카테고리별 통계 등을 제공합니다.

## 참고 사항

현재 프롬프트 데이터는 프로그램 실행 중에만 유지됩니다.

프로그램을 종료하면 추가하거나 변경한 데이터는 초기화되며, 다음 실행 시 기본 제공 프롬프트부터 다시 시작합니다.
